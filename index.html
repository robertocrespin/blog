Tecnología y futuro del software

Origen, metodologías, lenguajes y carreras

Introducción y Objetivos

El software ha evolucionado junto con la computación y hoy impulsa servicios, empresas y herramientas cotidianas. Su desarrollo combina lenguajes, metodologías, datos y equipos con distintas especialidades.

Objetivos

  • Explicar hitos históricos y conceptos para comprender el desarrollo de software.
  • Presentar metodologías, lenguajes y áreas profesionales relacionadas.

Alcances

  • Visión introductoria desde la programación física hasta la nube y la IA.
  • Ejemplos de perfiles y herramientas sin sustituir formación especializada.

1. Origen e Historia del Software

Décadas de 1940 y 1950

Programar podía implicar cambiar cables e interruptores manualmente. Destaca Ada Lovelace por escribir un algoritmo estructurado para una máquina analítica.

Décadas de 1960 y 1970

Surgieron lenguajes que facilitaron expresar instrucciones claras para las computadoras.

Décadas de 1980 y 1990

La computación personal y la web ampliaron notablemente el acceso al software.

Años 2000 en adelante

La nube facilita desplegar servicios e infraestructura en internet, mientras la inteligencia artificial se consolida como campo protagónico.

2. Metodologías de Desarrollo

Modelo en Cascada

Organiza requisitos, diseño, código y pruebas en etapas lineales continuas.

Agile y Scrum

Trabajan de forma iterativa, entregando funcionalidades en ciclos cortos llamados sprints.

DevOps y CI/CD

Promueven la colaboración entre desarrollo y operaciones, automatizando integración y despliegues.

3. Lenguajes y Tecnologías Clave

JavaScript y TypeScript

Esenciales para el desarrollo web en el navegador y en el servidor mediante Node.js.

Python

Muy utilizado en inteligencia artificial, análisis de datos, automatización y backend.

Java, C# y SQL

Java y C# se usan en aplicaciones corporativas; SQL permite gestionar bases de datos relacionales.
